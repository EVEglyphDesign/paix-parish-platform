How to verify any of this

On a Mac or Linux machine: sha256sum <file> and compare the output against the fingerprint printed next to that file above.

On Windows: certutil -hashfile <file> SHA256.

For any repository: git clone <url> takes a full copy — including its entire commit history — onto your own machine. Nothing is held back.

A copy whose fingerprint differs is not the original. That is the whole test, and anyone can run it.
